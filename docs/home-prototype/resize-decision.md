# 形成中のリサイズで魚の文字配置を維持する

Context: 前回AIレビューは1440×900から390×844へ縮小すると、旧位置の魚が新目標へ泳ぎ直す間に文字が欠けると指摘した。コンセプト・試作の進行はユーザー合意済み。成果確認は別途必要。

Options: (1) リサイズごとに文字の目標位置を再生成し、魚を再集合させる。(2) 滞在開始時の文字配置を維持し、メッシュ全体の表示倍率と位置を画角へ合わせる。

Decision: AIの実装判断として(2)を採用。目標生成は初期化時だけ、魚の現在位置・速度は継続。表示変換とカメラの変更を同じresize処理で描画する。側方の遊泳目標も同じ座標系へ換算する。

Why: 初回表示と同じ文字順・形を維持でき、縮小後に集合完了を待たない。GPUの再初期化、座標textureの書換え、新しいイベント・RAFを必要としない。

Risks: PCから縮小したときは1行のまま、スマホから拡大したときは2行のまま。領域内に収まる純粋関数の検証は成功したが、魚文字の判読性、解放後の奥行き・密度感は未確認。ブラウザ起動とローカル待受の制約で画像取得はできていない。

Revisit: 起動可能な環境でPC開始→スマホ幅、スマホ開始→横向きの画像・動きを確認したとき。文字が読みにくい場合は表示幅や文字サイズを再調整する。人間の成果確認をもってreview_statusを更新する。
