# 解放済みの魚の奥行きと側方配置

Context: 前回レビューP2。名前の一様倍率が遊泳深度にも適用され、縦横回転でfarまたは水平画角外へ出た。試作実装と修正はユーザーの委任範囲。成果確認は別途必要。

Options: (1) far拡張とリサイズごとの遊泳目標補正。(2) シミュレーション座標は初回のまま、文字表示と遊泳表示の変換を分ける。

Decision: (2)。文字は従来のフィット、遊泳は横倍率のみ追従して縦位置・深度を固定。実際のz=0〜-35で滑らかにつなぐ。GPU位置・速度・目標をresizeで書き換えない。

Why: farを広げるだけでは逆方向回転の水平クリッピングを解消できない。固定座標と深度による接続なら、resizeで再初期化や目標への急な移動を要さず、名前と遊泳領域の異なる制約を両立できる。

Risks: 数学的なxyz投影検証は成功したが、GLSLの実描画・文字判読性・深度による投影接続の速度感・本文密度はブラウザ起動不可のため未確認。P1は残る。AI選択であり、人間の成果確認済みとはしない。

Revisit: 実行可能なブラウザ環境でPC/スマホの画像・動画を確認し、深度接続・魚サイズ・側方余白に不自然さがあれば再調整する。実機の発熱と長時間リソース計測も必要。
